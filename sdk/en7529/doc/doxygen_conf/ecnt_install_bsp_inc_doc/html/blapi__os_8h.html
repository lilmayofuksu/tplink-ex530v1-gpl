This function gets the SKB_VLAN_ID option on socket.

This function gets the SKB_VLAN_ID option for the socket referred to by the file descriptor sockfd.The value will be put in vlan_val. IP_SKB_VLAN_ID or IPV6_SKB_VLAN_ID option value will be get according to the value of family.

Parameters
[in]sockfdThe file descriptor of the socket that is to be manipulated.
[in]familyThe address domain of the socket,it can be AF_INET or AF_INET6.
[in]vlan_valPointer to the current SKB_VLAN_ID option value.
Return values
0Success.
1Fail.
